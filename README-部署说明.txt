深圳礼品展｜在线 HTML 报告部署说明

一、当前文件
- index.html：完整单文件响应式网页报告，CSS 与 JavaScript 已内嵌，无需安装依赖。
- 可直接上传到任意静态网站托管平台。

二、提交前必须修改
1. 打开 index.html，搜索“姓名：________”，替换为真实姓名。
2. 搜索“学号：________”，替换为真实学号。
3. 搜索“现场照片”与“photo-slot”，将 6 个照片占位替换为本人拍摄的现场照片。
4. 将样本 A–F 替换为现场真实品牌、产品名称、展位号和证据编号。
5. 将参考资料中的“待补链接 / 待补文件 / 待补记录”替换为真实来源、链接和访问日期。
6. 如果实际访谈与样本数量不同，请同步修改页面中的 18、06 等计划数字。
7. 保持 HTML、PPT、海报的题目、作者、参观点与核心结论一致。

三、如何预览
方法一：直接双击 index.html，用浏览器打开。
方法二：在 PowerShell 中进入本文件夹并运行：
python -m http.server 8080
然后打开 http://localhost:8080

注意：localhost 只能自己查看，不能作为作业提交链接。

四、如何发布为在线链接
推荐平台（任选其一）：
1. GitHub Pages
   - 新建公开仓库，上传 index.html。
   - Settings → Pages → Deploy from a branch → main / root。
   - 等待部署完成，得到 https://用户名.github.io/仓库名/ 链接。
2. Netlify Drop
   - 打开 app.netlify.com/drop。
   - 将“深圳礼品展_在线HTML报告”整个文件夹拖入。
   - 获得公开 HTTPS 链接。
3. Vercel 或 Cloudflare Pages
   - 新建静态项目，上传本文件夹或连接 Git 仓库。
   - 构建命令留空，输出目录填写当前文件夹。

五、二维码流程
1. 先完成 HTML 报告并发布，获得最终公开 HTTPS 链接。
2. 打开链接，用手机测试页面导航、图片和手机适配。
3. 用最终链接生成高分辨率二维码 PNG 或 SVG。
4. 将二维码放在主题海报右下角，四周留出空白，印刷尺寸不小于 25 mm × 25 mm。
5. 再次用至少一部手机扫码，确认能直接打开本报告。

六、提交前自检
□ 页面可通过公开 HTTP/HTTPS 链接访问，无需登录。
□ 手机上无横向溢出，图片不变形，导航可用。
□ 姓名、学号、参观点、报告题目完整。
□ HTML、PPT、海报三份成果内容一致。
□ 所有现场照片、品牌信息、数据和公开资料均可追溯。
□ 二维码指向最终发布的 HTML 链接，而不是 PPT、网盘或本地文件。
